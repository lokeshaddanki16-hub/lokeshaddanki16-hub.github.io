Privacy Policy — SuperstarGambit Uploader

Effective date: October 28, 2026

Operator / developer: Lokesh Addanki (contact: lokesh.addanki16@gmail.com)

1. What this app is

SuperstarGambit Uploader ("the app") is a private, single-user tool run by its owner's personal AI assistant (Grok Bot) on the owner's private cloud workspace. It is operated by Lokesh Addanki solely to manage his own YouTube channel, SuperstarGambit (@superstargambit, channel ID UCTDMWlrZJehl6a6kzTrGYDQ). It is not offered, sold, or distributed to anyone else.

2. Use of YouTube API Services

The app uses YouTube API Services (the YouTube Data API v3 and the YouTube Analytics API). By using the app, you agree to be bound by the YouTube Terms of Service: https://www.youtube.com/t/terms.

Google's handling of your data is described in the Google Privacy Policy: https://policies.google.com/privacy.

3. What data the app accesses

After the channel owner signs in with Google and grants consent, the app requests these OAuth scopes:

ScopeWhy it is needed
https://www.googleapis.com/auth/youtube.uploadUpload the owner's own videos (videos.insert).
https://www.googleapis.com/auth/youtubeEdit the owner's own video titles, descriptions, tags, privacy status and scheduled publish time (videos.update), set custom thumbnails (thumbnails.set), and read the owner's channel and video details (channels.list, videos.list).
https://www.googleapis.com/auth/yt-analytics.readonlyRead the owner's own channel statistics (views, watch time, subscribers, etc.) for weekly performance reports (reports.query). Read-only.

The app accesses only the authenticated owner's own channel. It does not access other users' accounts, comments, subscriptions, or private data of any other person. It does not request your Google password.

4. How data is used

  • To upload the owner's original videos and set their metadata and thumbnails.
  • To read the owner's own channel/video statistics and produce private weekly reports for the owner.
  • The app never changes a video's privacy status without the owner's explicit instruction.

Data is not used for advertising, profiling, selling, credit decisions, or training AI models.

5. How data is stored

  • OAuth tokens: stored only in a private file in the owner's cloud workspace, used only to make the API calls above.
  • Statistics / reports: channel and video statistics retrieved from the YouTube Analytics and Data APIs may be saved in private report files in the owner's workspace for the owner's own records.
  • Other API data (e.g. video titles or descriptions returned by the API) is kept only as long as needed for the task and is refreshed or deleted within 30 days.
  • The app has no database, website backend, or user accounts of its own.

6. How data is shared

The app does not share, sell, rent, or transfer any YouTube or Google user data to any third party. Data is sent to Google/YouTube servers as part of the API calls, and is processed by the owner's own AI assistant (Grok Bot) only to carry out the owner's requests and write the owner's private reports. Reports are shared only with the owner.

7. Cookies and tracking

The app does not use cookies, device identifiers, analytics SDKs, or any tracking technology. These web pages do not set cookies.

8. How to revoke access and delete data

  • You can revoke the app's access at any time from the Google security settings page: https://myaccount.google.com/permissions (also reachable at https://security.google.com/settings/security/permissions). After revocation the app can no longer call YouTube on your behalf.
  • To delete locally stored data, delete the app's token file and report files. Following revocation, any remaining stored API data is deleted as soon as possible and in any case within 30 days.
  • You may also email lokesh.addanki16@gmail.com to request deletion.

9. Children

The app is not directed to children and is used only by its adult owner.
